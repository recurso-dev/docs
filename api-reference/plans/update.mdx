---
title: "Update a Plan"
openapi: "PUT /v1/plans/{id}"
description: "Update or archive a plan."
---

## Example request

```bash
curl -X PUT https://api.recurso.dev/v1/plans/3e7a9c52-1b4d-4f8e-a6c3-2d5b8e9f0a14 \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Pro (2026)"
  }'
```

Existing subscriptions keep billing at the price they signed up with —
plan edits affect new subscriptions. Archive a plan to stop new signups
without touching current subscribers.
