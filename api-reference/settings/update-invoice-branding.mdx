---
title: "Update Invoice Branding"
openapi: "PUT /v1/settings/invoice-branding"
description: "Create or update the tenant's invoice presentation settings."
---

Upserts the tenant's invoice presentation settings. Logo and signature must be
`data:image/png` or `data:image/jpeg` base64 URLs, at most 300KB decoded.
Presentation only — statutory seller identity (GST / W-9) still takes
precedence on tax invoices.

## Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `company_name` | string | No | Display name shown at the top of invoices (max 200 chars). |
| `logo_data_url` | string | No | Logo as a `data:image/png` or `data:image/jpeg` base64 URL (max 300KB decoded). |
| `signature_data_url` | string | No | Signature image, same format and limit as the logo. |
| `signatory_name` | string | No | Name printed under the signature line (max 200 chars). |
| `bank_details` | string | No | Bank/remittance details shown in the invoice footer (max 4000 chars). |
| `terms` | string | No | Terms and conditions shown in the invoice footer (max 4000 chars). |

## Example Request

```bash
curl -X PUT https://api.recurso.dev/v1/settings/invoice-branding \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "company_name": "Acme Corporation",
    "signatory_name": "Ada Admin",
    "terms": "Payment due within 15 days of the invoice date."
  }'
```

The saved settings are echoed back in the `data` envelope.
