---
title: "Update MCP Server Settings"
openapi: "PUT /v1/settings/mcp"
description: "Opt the tenant in or out of Tier-3 (money-path) MCP tools."
---

Upserts the tenant's MCP opt-in. Enabling `tier3_enabled` lets AI agents run
money-path / destructive MCP tools — convert a quote to an invoice, cancel a
subscription, issue a credit note, top up a wallet, and similar — against this
tenant. Off by default.

## Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `tier3_enabled` | boolean | No | Allow AI agents to run money-path / destructive MCP tools. Off by default. |

## Example Request

```bash
curl -X PUT https://api.recurso.dev/v1/settings/mcp \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "tier3_enabled": true
  }'
```

## Example Response

```json
{
  "data": {
    "tier3_enabled": true
  }
}
```
