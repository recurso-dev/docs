---
title: "Export the General Ledger (CSV)"
openapi: "GET /v1/ledger/export"
description: "Download every posted ledger transaction as CSV — optionally scoped to one calendar month or one legal entity."
---

Streams the general ledger as a CSV download: every posted transaction with
both account codes and names, the amount (smallest currency unit), the
reference it came from, and journal provenance. Read-only — this is the export
an auditor imports, and the file the month-end close pack links to.

## Query Parameters

| Parameter   | Type   | Required | Description                                                                 |
|-------------|--------|----------|-----------------------------------------------------------------------------|
| `month`     | int    | No       | Calendar month `1–12`. Pass together with `year` to export one month's postings. |
| `year`      | int    | No       | Calendar year. Pass together with `month`.                                   |
| `entity_id` | string | No       | Scope the export to one legal entity's ledger (Multi-Entity Books).          |

Omit `month`/`year` for the full ledger since inception. When a period is
given, the `Content-Disposition` filename carries it
(`general-ledger-2026-08.csv`), so the file name always states exactly what it
contains.

## Example Request

```bash
# August 2026 only — the month-end close's period export
curl "https://api.recurso.dev/v1/ledger/export?month=8&year=2026" \
  -H "Authorization: Bearer $API_KEY" \
  -o general-ledger-2026-08.csv
```

## Response

`200` — `text/csv`. Columns:

```text
transaction_id,timestamp,code,debit_account_code,debit_account_name,credit_account_code,credit_account_name,amount,reference_id,description,accounting_version
```

`400` — `month` without `year` (or vice versa), or values out of range.
