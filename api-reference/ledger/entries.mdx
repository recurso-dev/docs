---
title: "List Ledger Entries"
openapi: "GET /v1/ledger/entries"
description: "List a ledger account's raw transactions — each one balanced transfer: a single debit account, a single credit account, and a positive amount."
---

Recurso's ledger is **transfer-based**: every row is exactly one debit account,
one credit account, and a positive `amount` in minor units — never a multi-leg
compound entry. A posting's `code` names its kind (`1` = invoice issuance,
`3` = payment, `6` = tax reclass, …) and its `reference_id` points at the source
object (an invoice or payment id).

The ledger is queried **one account at a time**, so `account_id` is required.
Narrow to a single posting kind with `code`, and page with `limit` / `offset`.

<Note>
  There are no `start_date` / `end_date` filters on this endpoint. To read every
  posting behind a single invoice, use that invoice's journal entries; to pull a
  full period across all accounts, use the [General Ledger export](/api-reference/ledger/export).
</Note>
