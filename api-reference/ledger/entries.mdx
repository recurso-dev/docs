---
title: "List Ledger Entries"
openapi: "GET /v1/ledger/entries"
description: "Retrieve the postings that touch one ledger account, filtered by posting code and paged with limit/offset."
---

## Query Parameters

| Parameter    | Type   | Required | Description                                                         |
|--------------|--------|----------|---------------------------------------------------------------------|
| `account_id` | string (uuid) | **Yes** | The ledger account whose postings to list — rows where it is either the debit or the credit side. |
| `code`       | int    | No       | Filter to one posting code (e.g. `1` invoice, `3` payment, `6` tax reclass). |
| `limit`      | int    | No       | Maximum number of entries to return. Defaults to `50`.              |
| `offset`     | int    | No       | Number of entries to skip for pagination. Defaults to `0`.          |

Each row is exactly one balanced transfer — a single debit account, a single
credit account, and one amount in minor currency units. A business event that
touches several accounts (an invoice with tax, say) posts several rows
sharing the same `reference_id`. There is no date-range filter; results come
back newest first, so page by `limit`/`offset`.

## Example Request

```bash
curl "https://api.recurso.dev/v1/ledger/entries?account_id=e8f2d6b4-9a1c-4e7f-b3d5-6c8a0e2f4b19&code=3&limit=2" \
  -H "Authorization: Bearer $API_KEY"
```

for codes 1 and 6, the payment's invoice for code 3, the credit note or
