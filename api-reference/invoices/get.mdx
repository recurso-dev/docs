---
title: "Get Invoice"
openapi: "GET /v1/invoices/{id}"
description: "Retrieve a single invoice by id"
---

One invoice, scoped to the authenticated tenant. A foreign or missing id
returns a flat `404` — existence is never confirmed across tenants.

## Example Request

```bash
curl "https://api.recurso.dev/v1/invoices/inv_abc123" \
  -H "Authorization: Bearer $API_KEY"
```
