---
title: "Get a Customer"
openapi: "GET /v1/customers/{id}"
description: "Fetch one customer by ID."
---

## Example request

```bash
curl https://api.recurso.dev/v1/customers/9f2c1e84-6a3d-4b7e-9c21-8f4a5d6e7b01 \
  -H "Authorization: Bearer $API_KEY"
```

Customers are tenant-scoped: a foreign or missing ID returns a flat `404`.
The response wraps the customer in the standard `data` envelope — the full
field list is in the schema panel on the right.

## Errors

| Status | Code | When | Fix |
|--------|------|------|-----|
| 400 | `validation_failed` | `id` is not a valid UUID. | Pass the customer's UUID. |
| 401 | `unauthorized` | API key missing or invalid (`invalid_api_key`), or a live/test mode mismatch (`key_mode_mismatch`). | Send `Authorization: Bearer <api_key>` with a key for the right mode. |
| 404 | `not_found` | No customer with that ID exists in your tenant (IDs from another tenant also return 404). | Check the ID, and that the key belongs to the tenant that owns the customer. |

See [Errors](/api-reference/errors) for the error envelope and the full code taxonomy.
