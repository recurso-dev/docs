---
title: "Get Dunning History"
openapi: "GET /v1/analytics/dunning/history"
description: "Retrieve historical dunning retry data with per-attempt outcomes."
---

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `limit` | integer | No | Maximum number of records to return, newest first. Default `50`, capped at `500`; a non-positive value falls back to the default. |

There is no date-range, invoice or offset filter: the endpoint is a recent-activity log, and the response is cached for up to 5 minutes.

## Example Request

```bash
curl -X GET "https://api.recurso.dev/v1/analytics/dunning/history?limit=10" \
  -H "Authorization: Bearer rsk_live_7f3a9b2c1d4e8f0a"
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (uuid) | Unique identifier for the dunning history entry. |
| `tenant_id` | string (uuid) | The tenant the attempt belongs to. |
| `invoice_id` | string (uuid) | The invoice this dunning attempt was made against. |
| `context_key` | string | The dunning context state (e.g. `past_due_3d`, `past_due_7d`). |
| `action_id` | string | The dunning action that was taken (e.g. `retry_payment`, `send_reminder_email`). |
| `retry_interval` | integer | Seconds between the failed payment and this retry attempt. |
| `outcome` | string | Result of the attempt: `success` or `failure`. |
| `reward` | number | The reinforcement-learning reward assigned to this outcome: `1.0` for success, `0.0` for failure. |
| `created_at` | string | ISO 8601 timestamp of when the attempt occurred. |

<Tip>
Use this endpoint alongside the [dunning weights](/api-reference/analytics/dunning-weights) endpoint to understand how the AI agent is learning from past retry outcomes.
</Tip>
