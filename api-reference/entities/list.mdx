---
title: "List Entities"
openapi: "GET /v1/entities"
description: "List the tenant's legal entities (Multi-Entity Books), primary first."
---

Every tenant has exactly one primary entity; additional entities each carry
their own isolated ledger (`tb_ledger_id`) and invoice-number series. On
other resources, a `NULL`/omitted `entity_id` means the primary entity.

## Example request

```bash
curl https://api.recurso.dev/v1/entities \
  -H "Authorization: Bearer $API_KEY"
```

## Example response

```json
{

      "name": "ACME India",

      "is_primary": true,
      "tb_ledger_id": 1,
      "invoice_prefix": "ACME-IN",

      "created_at": "2026-05-02T09:00:00Z",

    }

```
