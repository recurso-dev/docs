---
title: "Get an Entity"
openapi: "GET /v1/entities/{id}"
description: "Fetch one legal entity by ID."
---

## Example request

```bash
curl https://api.recurso.dev/v1/entities/e1a7c3f9-8b2d-4e6a-9f0c-3d5b7a1e8c42 \
  -H "Authorization: Bearer $API_KEY"
```

## Example response

```json
{
  "data": {
    "id": "e1a7c3f9-8b2d-4e6a-9f0c-3d5b7a1e8c42",
    "tenant_id": "7d3e9a12-5b8c-4f6a-9e2d-1c7b4a8f0e35",
    "name": "ACME US",
    "legal_name": "ACME Inc.",
    "is_primary": false,
    "tb_ledger_id": 2,
    "invoice_prefix": "ACME-US",
    "country_code": "US",
    "created_at": "2026-08-12T10:00:00Z",
    "updated_at": "2026-08-12T10:00:00Z"
  }
}
```

`tb_ledger_id` is the entity's isolated ledger (the primary entity's is `1`);
`invoice_prefix` heads its gapless invoice-number series.
