---
title: "Request a Password Reset"
openapi: "POST /auth/forgot-password"
description: "Email a single-use password-reset link to an account."
---

Requests a password-reset link. Always returns `200` with a generic message,
whether or not the account exists — no user enumeration. If the account does
exist, a single-use reset token is created and a reset link is emailed to the
user; the link's token is consumed by
[`POST /auth/reset-password`](/api-reference/auth/reset-password).

## Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `email` | string | Yes | The account's email address. |

## Example Request

```bash
curl -X POST https://api.recurso.dev/auth/forgot-password \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@acme.com"
  }'
```

## Example Response

```json
{
  "message": "If an account with that email exists, a password reset link has been sent."
}
```
