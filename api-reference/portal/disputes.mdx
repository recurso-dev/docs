---
title: "List Customer Disputes"
openapi: "GET /portal/api/disputes"
description: "List the logged-in portal customer's invoice disputes"
---

<Note>
Portal endpoints authenticate via the `portal_session` cookie issued by [magic-link verification](/api-reference/portal/auth-verify) — not a Bearer API key. Non-browser clients may send the token in the `X-Portal-Session` header instead.
</Note>

Returns every dispute the authenticated customer has raised against their own invoices, open or resolved.

## Example Request

```bash
curl "https://api.recurso.dev/portal/api/disputes" \
  -b "portal_session=$PORTAL_SESSION"
```
