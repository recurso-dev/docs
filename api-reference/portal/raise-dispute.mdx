---
title: "Raise an Invoice Dispute"
openapi: "POST /portal/api/invoices/{id}/dispute"
description: "Raise a dispute or query on one of the logged-in customer's own invoices"
---

<Note>
Portal endpoints authenticate via the `portal_session` cookie issued by [magic-link verification](/api-reference/portal/auth-verify) — not a Bearer API key. State-changing portal calls must additionally echo the `portal_csrf` cookie's value in the `X-CSRF-Token` header (double-submit CSRF).
</Note>

Opens a dispute on the given invoice. The invoice must belong to the authenticated portal customer, otherwise a `404` is returned (existence is not leaked). At most one open dispute exists per invoice: re-raising updates the reason of the existing open dispute.

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string (uuid) | Yes | The invoice ID. Must belong to the authenticated customer. |

## Request body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `reason` | string | Yes | Why the customer is disputing the invoice. |

## Example Request

```bash
curl -X POST "https://api.recurso.dev/portal/api/invoices/3c9e1f57-2b8a-4d6c-9f0e-5a7b3d1c8e42/dispute" \
  -b "portal_session=$PORTAL_SESSION; portal_csrf=$CSRF_TOKEN" \
  -H "X-CSRF-Token: $CSRF_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "reason": "I was charged twice for this invoice."
  }'
```
