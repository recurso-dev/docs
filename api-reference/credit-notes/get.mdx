---
title: "Get Credit Note"
openapi: "GET /v1/credit-notes/{id}"
description: "Retrieve a single credit note by id"
---

One credit note, scoped to the authenticated tenant. A foreign or missing
id returns a flat `404` — existence is never confirmed across tenants.

## Example Request

```bash
curl "https://api.recurso.dev/v1/credit-notes/cn_abc123" \
  -H "Authorization: Bearer $API_KEY"
```

## Response

```json
{
  "data": {
    "id": "cn_abc123",
    "customer_id": "cust_abc123",
    "invoice_id": "inv_def456",
    "status": "issued",
    "reason": "billing_error",
    "currency": "USD",
    "amount": 5000,
    "balance": 5000,
    "created_at": "2026-08-01T09:00:00Z"
  }
}
```
