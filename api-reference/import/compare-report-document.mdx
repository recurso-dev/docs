---
title: "Compare Report Document"
openapi: "GET /v1/import/compare-reports/{id}/document"
description: "Printable receipt of a stored Compare run."
---

Returns a self-contained HTML document (print-to-PDF ready) stating what was
checked, what matched, and the verdict — the artifact to file alongside a
migration sign-off. The response is `text/html`, not JSON.

## Example request

```bash
curl https://api.recurso.dev/v1/import/compare-reports/b6d2f8a4-9c1e-4b3a-8e7f-5a2d9c0b6f14/document \
  -H "Authorization: Bearer $API_KEY" \
  -o compare-receipt.html
```

A missing or foreign ID returns `404`.
